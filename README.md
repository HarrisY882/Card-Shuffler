# Card-Shuffler
This project is a difficult first project ive decided to take on because i thought it was something i was more intrested in and could grow my skills, whilst also teaching me about gears.  This works by sending cards into 2 sides of the machine, and when the crank is turned, the machine gears will move in unison, mixing them up, therefore when repeated it will shuffle the cards.
